# 知识库资料整理格式规范

## 一、目录结构

```
knowledge/buddhism/
├── main.txt              # 通用佛教基础知识
├── faq.txt               # FAQ 问答对（固定格式：【Q】/【A】）
├── alias.txt             # 术语别名（一行一组）
│
├── 入菩萨行论.txt          # 独立论典（一部论一个文件）
├── 金刚经.txt
├── 中论.txt
│
├── 讲记/                  # 按类型分子目录
│   ├── 菩提心讲记.txt
│   └── 禅修开示.txt
├── 仪轨/
│   └── 金刚萨埵修法.txt
├── 问答/
│   └── 修行问答集.txt
└── 公案/
    └── 碧岩录选.txt
```

**原则：一部论典/一个主题 = 一个 .txt 文件**，不要把多部论混在同一个文件里。


## 二、各类型格式要求

系统会自动检测内容类型，但需要你的文本包含足够的**格式标记**。
以下是每种类型需要的最低标记数量和写法。

---

### 1. 科判类（论典讲解）
**触发条件**：前200行中出现 甲一/乙一/丙一... 格式的标记

```
甲一、论名与译礼

（正文内容）

乙一、礼赞句

颂词：
善逝法身佛子伴，及诸应敬我悉礼。
今当依教略宣说，趣入佛子律仪行。

讲解：
这两句是寂天菩萨的礼赞。善逝即佛陀……

乙二、立誓句

颂词：
此论未宣昔未有，诗韵吾亦不善巧。

讲解：
寂天菩萨非常谦虚……

甲二、正论

丙一、菩提心利益

（内容）
```

**关键格式要求**：
- 科判标记必须**独占一行**，以天干开头：甲、乙、丙、丁、戊、己、庚、辛、壬、癸
- 后跟中文数字：一、二、三……十
- 可带括号说明：`丙一（真实宣说）分三`
- 科判内部的颂词用 `颂词：` 开头
- 讲解用 `讲解：` 或 `释：` 开头
- 公案用 `公案：` 开头
- 问答用 `问：` 和 `答：` 开头

**这样系统会保证**：颂词+讲解不拆开，问+答不拆开，公案完整保留。

---

### 2. 品结构类（经典原文）
**触发条件**：出现 ≥2 个品标记

```
第一品 菩提心利益

（品的正文内容……）

第二品 忏悔罪业

（品的正文内容……）
```

**格式要求**：
- `第X品` 或 `X品第X` 独占一行
- 品名可带副标题：`第一品 菩提心利益`

---

### 3. 仪轨类
**触发条件**：出现 ≥3 个仪轨标记

```
金刚萨埵修法仪轨

一、前行

（合掌）
南无本师释迦牟尼佛（念三遍）

皈依发心
诸佛正法贤圣僧，直至菩提永皈依。
我以所修诸善根，为利有情愿成佛。（念三遍）

二、正行

观想
在自己头顶上方……

持咒
唵班扎萨埵吽（念一百零八遍）

三、回向

愿以此功德，庄严佛净土。
上报四重恩，下济三途苦。（念三遍）
```

**可用的标记词**（系统会识别）：
- 动作指令：`（合掌）`、`（顶礼）`、`（三拜）`、`（跪）`、`（问讯）`
- 念诵指令：`（念三遍）`、`（念诵）`、`（唱诵）`、`（默念）`
- 咒语开头：`唵`、`嗡`、`南无`
- 固定文体：`皈依`、`发愿文`、`回向文`、`回向偈`、`忏悔文`
- 回向句：`愿以此功德`、`上报四重恩`
- 分段标记：`前行`、`正行`、`结行`、`回向`、`发愿`、`观想`、`持咒`

---

### 4. 问答类
**触发条件**：出现 ≥2组 问+答 配对

```
问：什么是四圣谛？
答：四圣谛是佛陀初转法轮时所说的核心教义，
即苦谛、集谛、灭谛、道谛。

问：因果是否意味着宿命论？
答：绝对不是。因果是缘起的法则，它强调
我们当下的行为会影响未来。
```

**可用的问答标记**（任选一种，全文统一）：
- `问：` / `答：`（最推荐，简洁明确）
- `【Q】` / `【A】`
- `【问】` / `【答】`
- `弟子问：` / `上师答：`
- `居士问：` / `法师答：`
- `信众问：` / `堪布答：`

**重要**：问和答必须紧挨，中间不要插入无关内容。

---

### 5. 演讲/开示类
**触发条件**：出现 ≥2 个话题转换标记

```
今天我们讲菩提心的重要性。
菩提心是大乘佛法的核心……

下面我们谈一下如何发菩提心。
发菩提心有两种方式……

接下来讲自他交换法。
这是寂天菩萨特别强调的修法……
```

**可用的话题转换标记**：
- `今天讲……`、`今天我们讲……`
- `下面讲……`、`下面我们谈……`
- `接下来`、`接着讲`
- `首先`、`其次`、`再次`、`最后`
- `第一，`、`第二，`……

---

### 6. 方法/步骤类
**触发条件**：出现 ≥3 个步骤标记

```
如何修习禅定

第一步：选择合适的环境
找一个安静的地方……

第二步：调整坐姿
采用七支坐法……

第三步：调息
先做几次深呼吸……

注意事项
1）初学者每次15-20分钟即可
2）妄念很多不要急躁
3）坚持每天练习
```

**可用的步骤标记**：
- `第一步` / `第二步` ……
- `步骤一` / `步骤二` ……
- `要点一` / `要点二` ……
- `注意事项`、`要领`、`窍诀`、`关键`

---

### 7. 公案/语录类
**触发条件**：出现 ≥3 个公案标记

```
第一则

举：梁武帝问达摩大师：如何是圣谛第一义？
达摩云：廓然无圣。
帝曰：对朕者谁？
达摩云：不识。

颂曰：
圣谛廓然，何当辨的。

评唱：达摩一语截断万流……

第二则

举：赵州问南泉：如何是道？
南泉云：平常心是道。
```

**可用的标记**：
- 对话：`师云`、`僧问`、`祖曰`、`弟子问`
- 结构：`举：`、`颂：`、`颂曰：`、`评唱：`、`垂示：`
- 分则：`第一则`、`第二则`……

---

### 8. 注疏类
**触发条件**：出现 ≥4 个引用标记

```
「诸法不自生，亦不从他生，不共不无因，是故知无生。」

释：龙树菩萨以四句破析一切法的生起方式……

「如诸法自性，不在于缘中，以无自性故，他性亦复无。」

释：诸法的自性不存在于因缘之中……
```

**引文标记**（用以下任一格式包裹原文）：
- 「原文」或『原文』
- "原文"
- 《经名》
- `经云：`、`论曰：`、`颂云：`
- `原文：`、`正文：`、`颂词：`、`根本颂：`

**注释标记**：
- `释：`、`注：`、`解：`、`疏：`、`释义：`

---

### 9. 偈颂集
**触发条件**：≥6行等长短句，且占总行数30%以上

```
诸恶莫作，众善奉行。
自净其意，是诸佛教。

一切有为法，如梦幻泡影。
如露亦如电，应作如是观。

菩提本无树，明镜亦非台。
本来无一物，何处惹尘埃。
```

**格式要求**：
- 每行：3-12个汉字 + 逗号/句号 + 3-12个汉字 + 逗号/句号
- 偈颂之间用空行分隔
- 每首4-8行为宜

---

### 10. 书信类
**触发条件**：出现 ≥1 个书信标记

```
复周居士慈鉴：

来书悉知。学佛之人，当从信愿念佛入手。
净土法门，三根普被，利钝全收……

谨此敬颂法安
```

**称谓格式**：`某某 + 居士/法师/大德/道友 + 慈鉴/鉴/尊鉴/道鉴`
**落款格式**：`谨此/敬颂/即颂 + 法安/道安/吉祥`


## 三、通用注意事项

### 必须做的
1. **UTF-8 编码** — 保存为 UTF-8 格式的 .txt 文件
2. **标记独占一行** — 科判、品名、问：、答：、颂词：等标记必须单独成行
3. **空行分段** — 不同段落之间用空行隔开
4. **标记一致** — 同一文件内使用统一的标记风格（不要混用问：和【Q】）
5. **文件名有意义** — 用论典名或主题命名：`入菩萨行论.txt`，而非 `file1.txt`

### 不要做的
1. **不要在标记前加空格** — `甲一、` 必须顶格写，不要写成 `  甲一、`
2. **不要把标记和正文写在同一行** — 错误：`颂词：善逝法身佛子伴`
3. **不要多部论混在一个文件** — 每部论单独一个文件
4. **不要在问和答之间插入无关内容**
5. **不要使用富文本格式** — 不要用 Word/PDF，只用纯文本 .txt

## 五、整理后的自检清单

整理完一个文件后，用以下清单检查：

- [ ] 文件是 .txt 格式，UTF-8 编码
- [ ] 文件名是论典名或主题名（中文即可）
- [ ] 所有标记（科判/颂词/讲解/问/答）都独占一行
- [ ] 标记顶格写，前面没有空格
- [ ] 颂词和讲解紧挨在一起
- [ ] 问和答紧挨在一起
- [ ] 段落之间有空行
- [ ] 没有混入 markdown/HTML/Word 格式
- [ ] 内容没有被截断或遗漏
- [ ] 同一文件内标记风格统一
